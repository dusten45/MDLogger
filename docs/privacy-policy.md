# MDLogger 개인정보 처리방침

기존 시행일: **2026년 8월 22일** · 문구 정비일: **2026년 10월 26일**

이 방침은 MDLogger 웹/PWA와 Windows·Linux 데스크톱 앱의 데이터 처리 범위와 문의 방법을 안내합니다.

---

## 제1조 (개인정보의 처리 목적)

1. 회원 가입·인증, 비밀번호 재설정 및 계정 관리
2. 개인 경기 기록 저장·동기화, 본인 전적 통계 및 취향 설정의 수동 동기화
3. 게스트·회원 경기 관측을 이용한 듀얼 환경 분석
4. 비정상 요청 방지, 오류 진단 및 서비스 보안

---

## 제2조 (개인정보의 처리 및 보유 기간)

- **계정·개인 동기화 데이터**: 계정 삭제 시 서비스 DB에서 삭제합니다. 개별 경기 삭제는 삭제 표시를 남기는 방식이며, 중복 저장 방지 이력도 계정 삭제 전까지 유지됩니다.
- **분석 관측**: `analytics.duel_observations`에 별도 보관합니다. 현재 구현에는 관측과 철회 표시의 자동 삭제 기한이 없습니다. 계정 삭제만으로 분석 관측이 삭제되거나 철회되지는 않습니다.
- **Supabase 플랫폼 로그**: 현재 Free 요금제를 사용합니다. 공식 요금제표상 API·Database 로그 보유기간은 1일, Auth Audit Logs는 1시간입니다. 이는 서비스 DB의 경기·분석·진단 테이블에 적용되는 삭제 기한이 아닙니다.
- **서비스 DB의 진단·요청 제한 기록**: 플랫폼 로그와 별도로 저장하며 자동 정리 Cron은 설정되어 있지 않습니다. 정리 함수의 인자 기본값만으로 정기 삭제가 실행되지는 않습니다.
- **운영 DB 백업**: Supabase Free는 자동 백업·PITR을 제공하지 않으며 운영자의 별도 DB 백업도 없습니다. 이를 공급자 내부의 모든 보안·복구 사본이 존재하지 않는다는 의미로 안내하지는 않습니다.
- **Gmail 인증 메일**: 운영자의 개인 Gmail 계정에 저장되는 메일은 삭제 전까지 남을 수 있으며 MDLogger 계정 삭제로 자동 삭제되지 않습니다. Google의 정보 유형별 보관 정책이 적용되며 모든 메일·로그에 동일한 보유기간을 적용하지 않습니다.

## 제3조 (처리하는 개인정보의 항목)

### 1. 회원 계정
이메일, 비밀번호(인증 서버에서 해시로 저장), 로그인 일시와 인증 토큰을 처리합니다. 회원가입 화면에서 연령·약관·개인정보 동의를 확인하지만, 서버에 동의 버전·시각을 별도로 저장하지 않습니다. 데스크톱의 듀얼 데이터 안내 확인 상태는 기기에 저장합니다.

### 2. 회원의 개인 기록·설정 동기화
- 플레이 일시와 시간대 오프셋, 승패, 선·후공, 덱 분류, 턴 수, 종료 사유, 플레이 모드·문맥, 랭크·레이팅·이벤트 점수 변동, 환경·클라이언트 버전, 경기 식별자 및 개인 메모(`note`)
- 데스크톱 장치 식별자(`installation_id`), 플랫폼·장치 표시 이름·동기화 상태. 현재 데스크톱 장치 표시 이름에는 로그인 이메일이 사용됩니다.
- 사용자가 수동으로 동기화하는 테마·강조색·메모 사용 여부·기본 모드·점수 입력 방식
- 중복 저장 방지 이력(`game_create_receipts`): 요청 식별자, SHA-256 요청 해시, 경기 ID·버전과 처리 일시. 메모나 원문 요청 사본을 추가로 저장하지 않습니다.

### 3. 듀얼 환경 분석 데이터 (게스트 및 회원 공통)
경기 식별자, 플레이 시각(`played_at_local`)·시간대 오프셋(`timezone_offset_minutes`), 승패·선후공·덱·턴·종료 사유, 플레이 문맥·점수 변동, 환경·클라이언트·payload 버전을 별도 분석 관측으로 보관합니다. 회원은 개인 기록에서 허용된 항목을 추출하고, 게스트는 설치 식별자와 허용된 경기 항목을 전송합니다.

분석 관측에는 자유 입력 메모, 이메일, 표시 이름, 비밀번호·인증 토큰, 로컬 파일 경로와 OS 사용자명을 포함하지 않습니다. 계정 또는 설치 식별자에서 만든 가명 기여자 키와 경기 식별자를 사용하므로 완전한 익명 데이터라는 뜻은 아닙니다.

### 4. 네트워크·진단 정보
- 서비스 요청 시 IP 주소, User-Agent 등 네트워크 정보가 인프라에 전달됩니다. 게스트 요청 제한에는 IP 주소, 설치 식별자 기반 해시와 요청 횟수를 사용하며, 처리 건수·거부 이유 등 진단 정보를 저장합니다.
- 가입 인증·비밀번호 재설정 등 인증 메일 발송 시 수신 이메일 주소와 메일 제목·본문(인증·재설정 링크 등)이 Gmail SMTP로 전달됩니다. 경기 기록과 메모는 인증 메일에 포함하지 않습니다.
- 데스크톱 덱 목록 조회는 GitHub Gist에 요청하며 User-Agent는 `mdlogger-decks-sync`입니다.
- Windows 설치판은 시작 후 공개 GitHub Releases를 자동 확인합니다. 업데이트 확인·다운로드 요청의 User-Agent는 `MDLogger-Updater`이며 경기 기록·메모·이메일·인증 토큰·장치 식별자를 포함하지 않습니다. 설치 파일 다운로드·설치는 사용자가 선택한 후 진행합니다.

### 5. 로컬 데이터와 업데이트 캐시
- 게스트 메모는 분석 서버로 전송하지 않습니다. 게스트 기록을 회원 계정으로 가져오면 메모도 개인 기록 동기화 대상이 됩니다.
- 데스크톱의 UI 배율(`ui_scale`)·저사양 모드·애니메이션 감소, 웹의 글자 크기(`font_scale`)는 기기 전용 설정으로 동기화하지 않습니다.
- Windows 업데이트 캐시 `%LOCALAPPDATA%\MDLogger\updates`에는 설치 파일·서명·실행기·상태 및 진단 로그·재실행할 데이터 폴더 경로가 남을 수 있습니다. 경기 기록·로그인 토큰은 복사하지 않습니다. `MDLOGGER_DATA_DIR`과 별개이며 업데이트가 실행 중이 아닐 때 수동 삭제할 수 있습니다.

## 제4조 (개인정보의 제3자 제공)

현재 서비스는 이용자의 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 서비스 운영과 인증 메일 발송에 사용하는 외부 업체의 처리 범위는 제5조와 제6조에 안내합니다.

## 제5조 (개인정보 처리의 위탁)

- **Supabase, Inc.**: 데이터베이스, 사용자 인증 및 서버 함수(Edge Functions)
- **Cloudflare, Inc.**: 웹 정적 파일 호스팅(Workers Assets), CDN 및 네트워크 보안
- **Google LLC (Gmail)**: 운영자의 개인 Gmail 계정을 이용한 인증 메일 SMTP 발송

Cloudflare Workers Free의 정적 자산 전용 배포를 사용하며 사용자 정의 Worker 코드, Logpush, Tail Workers 및 Cron 작업은 사용하지 않습니다. 이것이 Cloudflare 자체의 네트워크·보안 기록까지 전혀 없다는 뜻은 아닙니다.

위탁 내용 또는 수탁자가 변경되면 이 방침에 반영합니다.

## 제6조 (개인정보의 국외 이전)

온라인 기능과 인증 메일 발송에는 아래 외부 인프라를 이용합니다. 제2조에 명시한 서비스 운영 범위와 별개로 공급자 내부의 처리 위치·보안 기록에는 각 공급자의 정책이 적용됩니다.

2026년 10월 26일 운영 메타데이터에서 확인한 Supabase 프로젝트 리전은 대한민국 서울(`ap-northeast-2`)입니다. 이는 인증·백업·지원·글로벌 전송의 모든 처리 위치를 뜻하지 않습니다.

- **Supabase, Inc.** (`privacy@supabase.com`): 가입·로그인·동기화·게스트 전송 시 계정, 개인 기록·설정·장치 정보와 분석 관측을 처리합니다.
- **Cloudflare, Inc.** (`privacyquestions@cloudflare.com`): 웹 접속 시 IP 주소·User-Agent·접속 일시 등 네트워크 정보를 처리합니다.
- **GitHub, Inc.** (`privacy@github.com`): 데스크톱 덱 목록 조회와 Windows 업데이트 확인·다운로드 시 IP 주소·User-Agent 등 요청 정보를 처리합니다.
- **Google LLC (Gmail)** (`googlekrsupport@google.com`): 인증 메일 발송 시 수신 이메일 주소와 제목·본문 등을 처리합니다. Google은 전 세계의 서버에서 정보를 처리하므로 이용자의 거주 국가 밖에서 처리될 수 있습니다.

Google의 개인정보처리방침(https://policies.google.com/privacy)과 데이터 보관 정책(https://policies.google.com/technologies/retention)이 적용됩니다. 특정 국가만 사용하거나 발송 메일이 일률적으로 1일 또는 30일 안에 지워진다고 보장하지 않습니다.

분석 전송만 끄는 전역 설정은 없습니다. 데스크톱은 네트워크 연결 없이 로컬 기록·내보내기를 이용할 수 있으나, 연결이 복구되면 전송이 재개됩니다. 웹/PWA의 경기 기능은 온라인 연결이 필요합니다. 계정 삭제는 향후 계정 이용을 종료하지만 이미 보관된 분석 관측을 삭제하지는 않습니다.

`MDLOGGER_DECKS_URL=` 설정은 덱 목록 조회만 끄며 분석 전송이나 Windows 자동 업데이트 확인을 끄지 않습니다.

## 제7조 (개인정보의 파기 절차 및 방법)

- **경기 수정·삭제**: 경기 수정이 서버에 반영되면 분석 관측도 갱신됩니다. 개별 경기 삭제는 개인 기록에 삭제 표시를 남기고, 분석 관측에는 철회 표시(`withdrawn_at`)를 남기며 관측 행 자체는 보존합니다. 게스트도 수정·철회 요청이 서버에 반영되어야 하며, 오프라인 변경이 즉시 서버에 적용되는 것은 아닙니다.
- **계정 삭제**: Auth 사용자와 연결된 개인 경기 기록(`games`), 프로필(`profiles`), 장치(`devices`), 동기화 커서(`game_change_cursors`), 설정(`user_settings`), 중복 저장 방지 이력(`game_create_receipts`)을 서비스 DB에서 삭제합니다. 계정 삭제만으로 분석 관측이 삭제되거나 철회되지는 않습니다.
- **앱 초기화**: 앱 초기화는 이 기기의 로컬 데이터 정리이며 서버 기록 삭제나 분석 관측 철회가 아닙니다. 로컬 DB·설정·경기 캐시·저장된 인증 토큰을 정리합니다. 실패하면 복구 자료를 보존하여 다음 실행에서 복구하고, 완료 후에는 이전 경기 데이터의 복구 사본을 남기지 않습니다. 별도 Windows 업데이트 캐시는 제3조의 수동 정리 대상입니다.

위 삭제는 서비스 DB와 로컬 파일의 처리 범위이며, 저장장치·공급자 내부 기록의 즉시 복구 불가능한 물리 삭제를 보장하지 않습니다. 다른 기기의 로컬 사본, 사용자가 내보낸 파일, Gmail과 수신자 메일함의 발송된 인증 메일 사본까지 원격으로 지우지는 않습니다.

## 제8조 (정보주체와 법정대리인의 권리·의무 및 행사방법)

기록 화면에서 개인 기록을 열람·수정·삭제하고, 설정의 계정 기능에서 데이터 내보내기와 계정 삭제를 요청할 수 있습니다. 열람·정정·삭제·처리정지 등 추가 요청은 제11조 이메일로 접수합니다.

계정 JSON 내보내기는 프로필·개인 경기 기록·등록 장치만 포함합니다. 경기 메모와 삭제 표시된 기록도 포함되므로 파일을 안전하게 보관해 주세요. 설정·인증 정보·분석 관측·중복 저장 방지 이력은 포함하지 않으며 전체 계정 백업이나 복원 파일이 아닙니다.

만 14세 미만은 회원가입을 할 수 없습니다. 해당 계정이 확인되면 삭제할 수 있으며, 분석 관측의 처리 범위는 제7조와 같습니다.

## 제9조 (개인정보의 안전성 확보 조치)

- 비밀번호 해시, HTTPS 전송 및 데이터베이스 행 단위 접근 제어(RLS)를 사용합니다.
- 데스크톱 Refresh Token은 OS 자격증명 저장소를 이용하며, 클라이언트에 서버 관리자 키를 넣지 않습니다.
- 분석 스키마는 일반 클라이언트의 직접 접근을 차단하고, POSIX 환경의 로컬 데이터에는 사용자 전용 권한을 적용합니다.

## 제10조 (개인정보 자동 수집 장치의 설치·운영 및 거부에 관한 사항)

웹/PWA는 localStorage에 로그인 세션과 설정을 보관하고, 서비스 워커는 정적 앱 파일을 캐시합니다. 경기 데이터를 IndexedDB에 영구 저장하거나 오프라인 전송 대기열에 보관하지 않습니다. 경기 조회·저장은 온라인 전용이며 API·인증 응답은 서비스 워커 캐시 대상이 아닙니다.

브라우저의 사이트 데이터 삭제로 세션·설정·캐시를 지울 수 있지만 서버 기록은 삭제되지 않습니다. 저장소를 차단하면 로그인 유지나 설정 저장이 제한될 수 있습니다. 광고 트래커나 제3자 마케팅 분석 도구는 사용하지 않습니다.

## 제12조 (정보주체의 권익침해에 대한 구제방법)

개인정보분쟁조정위원회(1833-6972, https://www.kopico.go.kr) 또는 개인정보침해신고센터(118, https://privacy.kisa.or.kr)에 상담·분쟁조정을 신청할 수 있습니다.

## 제13조 (개인정보 처리방침의 변경)

기존 시행일은 **2026년 8월 22일**입니다. **2026년 10월 26일**에 현재 구현에 맞게 문구를 정비했습니다. 문구 정비일은 새 시행일이나 사전 공지·배포 완료를 뜻하지 않습니다. 문서 변경 이력은 저장소에서 확인할 수 있습니다.
